# Meme Generator

Make memes in the browser: pick or upload an image, add text lines, style them and download the result.

**Live demo:** https://yahavmor.github.io/Meme-generator/

<img width="1647" height="908" alt="Meme-generator screenshot" src="https://github.com/user-attachments/assets/faad285b-823a-4463-9762-65844c7a4846" />

## Features

- Image gallery with keyword search, plus an "I'm flexible" button for a random meme
- Upload your own image
- Multiple text lines: add, switch, edit and delete
- Font family, size, color and alignment for each line
- Download as JPG, save memes to a local gallery (localStorage), and share to Facebook

## Tech

HTML, CSS, vanilla JavaScript and the Canvas API.

## Run locally

Open `index.html` in a browser.
